### Version 0.0.9 <sub>*(09/22/2026)*</sub>

#### Technical Style & Logic
* Now depends on LibAPH, a shared helper library for my addons.
* Added a <kbd>Module Manager</kbd> - the Wizard, Menu, Migration, and UI modules can each be
  soft-disabled independently (/alcunloadwizard, /alcunloadmenu, /alcunloadmigration, /alcunloadui).
* New <kbd>Codebase changes</kbd>, various stability and settings-menu fixes across PC and Console and
  language localization support.

#### Memory Pool Cleanup
* Added <kbd>Auto Pool Cleanup After Travel</kbd> - watches for you traveling and reloads the UI
  afterward if the addon memory pool is worth clearing, or if you set a specific custom threshold
  for clearing.
* Improved the accuracy of the <kbd>Pool Cleanup report</kbd> with an adaptive re-check.

#### UI & Console Updates
* Added a <kbd>Setup Wizard</kbd> on first install to ask your preferences.
* Added LibHarvensAddonSettings support for the <kbd>console Settings Menu</kbd>.
* Fixed <kbd>Chat output</kbd> on console for slash commands.
* Added a <kbd>Library Warning Messages</kbd> toggle to enable or disable the optional-library popup,
  screen announcement, and chat reminder on their own (/alclibwarn).
* Updated the optional-library <kbd>chat and screen announcement messages</kbd> to clearly state
  whether LibAddonMenu or LibHarvensAddonSettings is missing, disabled, or outdated, with the popup
  and screen announcement now shown only once instead of on every reload.
* Added settings-menu <kbd>submenus remembering</kbd> whether they were left open or closed across a
  reload.
* Added the ability to resize the memory status display by dragging its corner, with its text scaling
  to fit - Reset UI Size resets it back to default.

#### General Additions
* Updated <kbd>Bug Report</kbd>.
* Removed <kbd>Live statistics</kbd> in favor of Client information for easier bug tracking and
  stability.
* Updated <kbd>Bug Report</kbd> to open on its own when a new error is captured, and to count repeated
  occurrences of the same error instead of piling them up separately.
* Added the ability to resize the <kbd>Bug Report</kbd> window, with its text scaling to fit.
* Fixed the mouse cursor staying locked to camera control when the <kbd>Bug Report</kbd> window
  auto-opens.

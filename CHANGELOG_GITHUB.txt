### Version 0.0.9 <sub>*(09/11/2026)*</sub>

#### Technical Style & Logic
* Now depends on <kbd>LibAPH</kbd>, a shared helper library for my addons.
* Added a <kbd>Module Manager</kbd> - the Wizard, Menu, Migration, and UI modules can each be
  soft-disabled independently (<kbd>/alcunloadwizard</kbd>, <kbd>/alcunloadmenu</kbd>,
  <kbd>/alcunloadmigration</kbd>, <kbd>/alcunloadui</kbd>).
* New Codebase changes, various stability and settings-menu fixes across PC and Console and
  language localization support.

#### Memory Pool Cleanup
* Added <kbd>Auto Pool Cleanup After Travel</kbd> - watches for you traveling and reloads the UI
  afterward if the addon memory pool is worth clearing, or if you set a specific custom threshold
  for clearing.
* Improved the accuracy of the <kbd>Pool Cleanup report</kbd> with an adaptive re-check.

#### UI & Console Updates
* Added a <kbd>Setup Wizard</kbd> on first install to ask your preferences.
* Added <kbd>LibHarvensAddonSettings</kbd> support for the console Settings Menu.
* Fixed <kbd>Chat output</kbd> on console for slash commands.
* Added a <kbd>Library Warning Messages toggle</kbd> to enable or disable the optional-library popup, screen announcement, and chat reminder on their own <kbd>(/alclibwarn)</kbd>.
* Updated the optional-library chat and screen announcement messages to clearly state whether <kbd>LibAddonMenu</kbd> or <kbd>LibHarvensAddonSettings</kbd> is missing, disabled, or outdated, with the popup and screen announcement now shown only once instead of on every reload.
* Updated settings-menu submenus remembering whether they were left open or closed across a reload.

#### General Additions
* Updated <kbd>Bug Report</kbd>.
* Removed Live statistics in favor of <kbd>Client information</kbd> for easier bug tracking and
  stability.
